# Kairos — Minerva Foods

Projeto pronto para subir no GitHub e publicar na Vercel.

## Arquivos do repositório

- `index.html` — aplicação Kairos completa.
- `vercel.json` — configuração para a Vercel abrir o sistema corretamente.
- `README.md` — descrição do projeto.

## Como subir no GitHub pelo navegador

1. Extraia o ZIP.
2. Entre na pasta extraída.
3. Selecione os arquivos `index.html`, `vercel.json` e `README.md`.
4. Arraste para a tela de upload do repositório no GitHub.
5. Clique em `Commit changes`.

Depois, importe o repositório na Vercel.
